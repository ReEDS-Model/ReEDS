## Load Input Files

### Load Growth Projections

The `demand_AEO_*` files are generated by [`aeo_updates/`](https://github.com/ReEDS-Model/ReEDS_Input_Processing/tree/main/aeo_updates) in the ReEDS_Input_Processing repo,
which combines EIA retail sales and behind-the-meter PV for historical years with AEO electricity
consumption growth for projected years.

Each file gives an annual load growth multiplier [unitless] by state (`r`) and year, normalized to
1.0 in the file's first year. `hourly_load.py` scales the historical hourly state load profiles to
match annual totals in that baseline year, then applies these multipliers to project load forward.
The scenario is chosen with the `demandscen` switch, and the file is copied into `inputs_case/` as
`load_multiplier.csv`.

- `demand_AEO_2025_high.csv`: Load growth projection from the AEO2025 High Economic Growth scenario

- `demand_AEO_2025_low.csv`: Load growth projection from the AEO2025 Low Economic Growth scenario

- `demand_AEO_2025_reference.csv`: Load growth projection from the AEO2025 Reference scenario

- `demand_AEO_2026_baseline.csv`: Load growth projection from the AEO2026 Counterfactual Baseline scenario

- `demand_AEO_2026_high.csv`: Load growth projection from the AEO2026 High Economic Growth scenario

- `demand_AEO_2026_low.csv`: Load growth projection from the AEO2026 Low Economic Growth scenario

### Load Growth Multipliers
- `cangrowth.csv`: Canadian load growth multiplier [unitless] by province and year, relative to the first year
  - Used only when `GSw_Canada` is on

- `mex_growth_rate.csv`: National Mexican load growth multiplier [unitless] by year, relative to 2016
  - Scales the exogenous Mexican load in each region and hour

### Other
- `EIA_loadbystate.csv`: Historical annual electricity load [MWh] by state and year, from EIA
  - Provides the annual totals that the historical hourly state load profiles are scaled to match

- `loadsite_country_test.csv`: Load trajectory [MW] to be optimally sited, by load-site region and year
  - The file is selected by the `GSw_LoadSiteTrajectory` switch and is only used when `GSw_LoadSiteCF` > 0
  - The first column may use any region hierarchy level (`st`, `transreg`, `transgrp`, `interconnect`, etc.), which must match the level named in the file title: `loadsite_{level}_{name}.csv`
