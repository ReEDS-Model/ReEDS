## Storage Input Files

- `cap_existing_psh.csv`: County-wide PSH operational capacity [MW/MWh], pump capacity, and max energy, based on plant-level data from [https://www.hydropower.org/hydropower-pumped-storage-tool](https://www.hydropower.org/hydropower-pumped-storage-tool)
  - Generated by [`psh/`](https://github.com/ReEDS-Model/ReEDS_Input_Processing/tree/main/psh) in the ReEDS_Input_Processing repo

- `PSH_supply_curves_durations.csv`: Storage duration [hours] of each pumped storage hydropower (PSH) supply curve
  - The duration of the supply curve named by the `pshsupplycurve` switch is applied to all PSH capacity, overriding the PSH values in `storage_duration.csv`
  - When `GSw_HydroPSHDurData` is on, region- and vintage-specific durations derived from `cap_existing_psh.csv` override this value for the existing PSH fleet

- `storage_duration.csv`: Storage duration [hours] by technology
  - Covers the PSH, CSP, and EVMC storage technologies
