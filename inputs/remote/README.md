## Remote Files

This folder holds downloaded copies of the input files that are hosted remotely and listed in `inputs/remote_files.csv`, so its contents depend on which files have been downloaded. Each file name ends with its `record_id`, which allows multiple versions of a file to be kept here. The current versions are linked into the appropriate `inputs/profiles_*` folders.

The data files in this folder are untracked and are not intended to be committed.
