## Disaggregation Input Files

- `county_population.csv`: The population of each county, relative values are used as multipliers for downselecting data
  - Data come from the U.S. Census Bureau 2021 county population estimates ([https://www.census.gov/data/tables/time-series/demo/popest/2020s-counties-total.html](https://www.census.gov/data/tables/time-series/demo/popest/2020s-counties-total.html)) 

- `county_state_lpf.csv`: Load participation factor [fraction] used to disaggregate state-level quantities to counties
  - Values sum to 1 within each state
  - Generated by `write_lpf_naris.py` in [`transmission/`](https://github.com/ReEDS-Model/ReEDS_Input_Processing/tree/main/transmission) of the ReEDS_Input_Processing repo, which aggregates NARIS nodal load to counties and normalizes within each state

- `disagg_hydroexist.csv`: The hydropower capacity fraction of each county within a given ReEDS BA, used as multipliers for downselecting data
