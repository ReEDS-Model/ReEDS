## State Policies Input Files

- `acp_disallowed.csv`: Flag [1 = disallowed, 0 = allowed] for alternative compliance payments, by state and RPS/CES category

- `acp_prices.csv`: Alternative compliance payment price [2004$/REC] for the RPS constraint, by state and year
  - Sets the effective ceiling on the RPS penalty; used only when `GSw_StateRPS` is on

- `ces_fraction.csv`: Annual compliance fraction [fraction] for states with a CES policy
  - Generated by [`state_policies/`](https://github.com/ReEDS-Model/ReEDS_Input_Processing/tree/main/state_policies) in the ReEDS_Input_Processing repo

- `forced_retirements.csv`: Year by which certain technologies must be retired, by technology and state

- `hydrofrac_policy.csv`: Fraction [fraction] of hydropower RPS or CES credits that can count toward policy targets, by state
  - Given separately for the `RPS_All` and `CES` policies
  - Generated by [`state_policies/`](https://github.com/ReEDS-Model/ReEDS_Input_Processing/tree/main/state_policies) in the ReEDS_Input_Processing repo

- `ng_crf_penalty_st.csv`: Cost adjustment [unitless] for NG techs in states where all NG techs must be retired by a certain year

- `nuclear_subsidies.csv`: Year in which an existing nuclear subsidy ends, by state

- `offshore_req_default.csv`: Default state mandates of offshore wind capacity [MW], updated in November 2025

- `oosfrac.csv`: Defines the fraction of renewable and clean energy credits can be purchased from out of state (oos). Applied for RPS and CES.

- `recstyle.csv`: Indication for how to apply state requirement (0 = end-use sales, 1 = bus-bar sales, 2 = generation). Default is 0.

- `rectable.csv`: Allowed REC trade from each state to each other state
  - `1` = unbundled trade allowed, `2` = only bundled trade allowed, `0` = no trade

- `rps_fraction.csv`: Fraction [fraction] of sales or generation (based on `recstyle.csv`) that must be from renewable energy, by state and year
  - Given separately for the overall requirement and any solar- or wind-specific carve-outs (`rps_all`, `rps_solar`, `rps_wind`)
  - Generated by [`state_policies/`](https://github.com/ReEDS-Model/ReEDS_Input_Processing/tree/main/state_policies) in the ReEDS_Input_Processing repo

- `storage_mandates.csv`: Cumulative battery storage mandate [MW] by state and year

- `techs_banned_ces.csv`: Technologies that may not contribute to a state's CES, by state
  - A value of 1 marks the technology as ineligible for that state's CES

- `techs_banned_imports_rps.csv`: Technologies that may not be imported into a state to meet its RPS, by state
  - A value of 1 marks the technology as banned for imports in that state

- `techs_banned_rps.csv`: Technologies that may not contribute to a state's RPS, by state
  - A value of 1 marks the technology as ineligible for all of that state's RPS categories (`RPS_All`, `RPS_Wind`, `RPS_Solar`)

- `techs_banned.yaml`: Technologies banned from being built in specific regions
  - The only allowed regional scopes (nested keys) are `st` and `county`

- `unbundled_limit_ces.csv`: Limit [fraction] on credits towards CES which can be purchased unbundled from other states

- `unbundled_limit_rps.csv`: Limit [fraction] on credits towards RPS which can be purchased unbundled from other states
