## Capacity Exogenous Input Files

- `cappayments_ba.csv`: Capacity payment to existing (pre-2010) generators [billion $] by region and year
  - Not used by the model itself (`runfiles.csv` marks it "not used"); it is read only by the BokehPivot system cost report, which inflates it and adds it to `inv_investment_capacity_costs`
  - Generated by [`existing_capacity_payments/`](https://github.com/ReEDS-Model/ReEDS_Input_Processing/tree/main/existing_capacity_payments) in the ReEDS_Input_Processing repo

- `demonstration_plants.csv`: Nuclear-smr demonstration plants [MW]
  - Active when `GSw_NuclearDemo = 1`
  - For more information, refer to the **notes** section of [https://www.energy.gov/oced/advanced-reactor-demonstration-projects-0](https://www.energy.gov/oced/advanced-reactor-demonstration-projects-0)

- `interconnection_queues.csv`: Near-term capacity [MW] in the interconnection queues by county, technology group, and year
  - Aggregated to model zones during input processing to form `cap_limit`, which caps total capacity deployed since the start of the interconnection queue data
  - Generated by [`interconnection_queues/`](https://github.com/ReEDS-Model/ReEDS_Input_Processing/tree/main/interconnection_queues) in the ReEDS_Input_Processing repo

- `ReEDS_generator_database_final_EIA-NEMS.csv`: ReEDS generator database derived from the EIA NEMS plant file and EIA 860M
  - Generated by [`nems_database_processing/`](https://github.com/ReEDS-Model/ReEDS_Input_Processing/tree/main/nems_database_processing) in the ReEDS_Input_Processing repo
