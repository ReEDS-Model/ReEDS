## dGen Input Files

- `stscen2023_electrification/distpvcap_stscen2023_electrification.csv`: Distributed PV summer capacity [MW] by region and year using electricity price outputs from the Standard Scenarios 2023 electrification scenario
    - Selected using `distpvscen`

- `stscen2023_highng/distpvcap_stscen2023_highng.csv`: Distributed PV summer capacity [MW] by region and year using electricity price outputs from the Standard Scenarios 2023 high natural gas price scenario
    - Selected using `distpvscen`

- `stscen2023_highre/distpvcap_stscen2023_highre.csv`: Distributed PV summer capacity [MW] by region and year using electricity price outputs from the Standard Scenarios 2023 high renewable energy cost scenario (including high distributed PV capital costs based on the 2023 Annual Technology Baseline)
    - Selected using `distpvscen`

- `stscen2023_lowng/distpvcap_stscen2023_lowng.csv`: Distributed PV summer capacity [MW] by region and year using electricity price outputs from the Standard Scenarios 2023 low natural gas price scenario
    - Selected using `distpvscen`

- `stscen2023_lowre/distpvcap_stscen2023_lowre.csv`: Distributed PV summer capacity [MW] by region and year using electricity price outputs from the Standard Scenarios 2023 high renewable energy cost scenario (including low distributed PV capital costs based on the 2023 Annual Technology Baseline)
    - Selected using `distpvscen`

- `stscen2023_mid_case/distpvcap_stscen2023_mid_case.csv`: Distributed PV summer capacity [MW] by region and year using electricity price outputs from the Standard Scenarios 2023 mid-case scenario
    - Selected using `distpvscen`

- `stscen2023_mid_case_95_by_2035/distpvcap_stscen2023_mid_case_95_by_2035.csv`: Distributed PV summer capacity [MW] by region and year using electricity price outputs from the Standard Scenarios 2023 95% CO<sub>2</sub> emission reduction by 2035 scenario
    - Selected using `distpvscen`

- `stscen2023_mid_case_95_by_2050/distpvcap_stscen2023_mid_case_95_by_2050.csv`: Distributed PV summer capacity [MW] by region and year using electricity price outputs from the Standard Scenarios 2023 95% CO<sub>2</sub> emission reduction by 2050 scenario
    - Selected using `distpvscen`

- `stscen2023_taxcredit_extended2050/distpvcap_stscen2023_taxcredit_extended2050.csv`: Distributed PV summer capacity [MW] by region and year using electricity price outputs from the Standard Scenarios 2023 mid-case scenario where tax credits (including for distributed PV) are extended through 2050
    - Selected using `distpvscen`
